# Diagnostic Assessment

Use this before beginning the program. Rate each item from 0–3:

- 0: unfamiliar
- 1: can recognize concepts
- 2: can solve standard problems
- 3: can teach/apply independently

## Math and theory

- Discrete math and proof techniques
- Linear algebra
- Probability and statistics
- Convex optimization
- Algorithms and data structures
- Complexity theory
- Automata and computability

## Systems

- C/C++ or Rust systems programming
- Operating systems internals
- Networking
- Distributed systems
- Databases
- Compilers/interpreters
- Computer architecture

## AI/ML

- Supervised and unsupervised learning
- Deep learning
- Reinforcement learning
- Probabilistic modeling
- Evaluation methodology
- ML systems and deployment

## Research readiness

- Reading academic papers
- Writing technical reports
- Designing experiments
- Reproducing results
- Benchmarking and statistical analysis
- Presenting research

## Output

Create a file named `personal-study-plan.md` with:

1. Your scores.
2. Top 5 weaknesses.
3. Modules to prioritize.
4. Weekly schedule.
5. First 90-day goals.
