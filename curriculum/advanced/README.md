Each module follows the same structure as the [core modules](../core/README.md): learning objectives, prerequisites, primary resources, seminal papers, assignments (problem sets, projects, and a paper critique), an AI study loop, and a mastery checklist.

## How to work an advanced module

Treat these as deeper, more research-facing versions of the core modules. Use the same four-pass model from [`milestones/roadmap.md`](../../milestones/roadmap.md) — foundation, problem, build, defense — but bias toward the seminal papers and the implementation project, since the point of an advanced module is to reach the current research frontier in that area. A reasonable target is two to four advanced modules concentrated in your primary [specialization](../specializations/README.md), plus one or two from an adjacent area for breadth.

The topic list is a starting point, not a ceiling. If your research needs a topic not covered here (quantum computing, computational biology, programming-language theory at depth, AI safety/alignment, …), create a new module file following the same template and add it to the appropriate section above.
