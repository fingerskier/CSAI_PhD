# Advanced Curriculum

Advanced modules deepen research maturity after the core phase.

## Suggested topics

- Advanced algorithms
- Randomized algorithms
- Cryptography and security
- Formal methods and verification
- Advanced machine learning
- Deep learning systems
- Reinforcement learning
- Natural language processing
- Computer vision
- Robotics and control
- High-performance computing
- Cloud, edge, and distributed infrastructure
- Human-computer interaction
- Scientific computing

For each selected topic, create a module file with objectives, resources, 10–20 papers, projects, and assessment rubrics.
