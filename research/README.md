# Research Program

This directory tracks the research side of the self-study PhD program.

## Workflow

1. Build a reading list.
2. Take structured paper notes.
3. Write short critiques.
4. Reproduce important results.
5. Identify gaps and open problems.
6. Draft research proposals.
7. Execute original projects.
8. Package artifacts reproducibly.

## Directories

- `reading-lists/` — curated papers by topic.
- `paper-notes/` — notes using `templates/paper-note.md`.
- `replication-projects/` — reproductions of published work.
- `proposals/` — original research proposals.
